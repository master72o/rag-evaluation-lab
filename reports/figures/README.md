# Figures Directory

This directory contains visualization charts generated by the RAG Evaluation Lab suite:
- `retrieval_metrics_comparison.png`: Comparison of Precision@K, Recall@K, MRR, and NDCG across RAG v1, v2, and v3.
- `generation_metrics_comparison.png`: Comparison of Faithfulness, Context Precision, and Citation Correctness across RAG v1, v2, and v3.
- `overall_rag_performance.png`: Overall composite RAG score progression and quality pass rate.
